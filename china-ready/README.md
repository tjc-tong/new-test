# 皖山茶集国内网络发布版

这个目录是纯静态版本，可以直接上传到国内服务器或对象存储。

特点：
- 不使用 Google 字体、海外 CDN、外链脚本或外链图片。
- 所有页面、样式、脚本和图片都在当前目录内。
- 图片已经压缩为本地 JPG，适合国内移动网络加载。

部署方式：
1. 上传 `china-ready` 目录里的全部文件到国内主机、阿里云 OSS、腾讯云 COS、七牛云、又拍云或其他国内静态托管服务。
2. 把网站入口设置为 `index.html`。
3. 如果要绑定正式域名，并且服务器在中国大陆，通常需要按服务商要求完成 ICP 备案。

本地预览：
- 访问 `http://127.0.0.1:5173/china-ready/index.html`
