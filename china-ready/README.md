# 皖山茶集 · 国内网络发布版

纯静态站点，上传即用，国内网络访问无障碍。

## 已做的国内适配

- ✅ 零海外依赖：无 Google 字体、无海外 CDN、无外链脚本
- ✅ 图片已压缩为 JPG（PNG 2MB → JPG ~150KB），适合移动网络
- ✅ 所有资源（HTML/CSS/JS/图片）都在本目录内，相对路径引用
- ✅ 添加 `X-UA-Compatible` 兼容国内常见浏览器（360、QQ、搜狗等 IE 内核模式）
- ✅ 字体使用系统原生字体栈，无需额外加载
- ✅ UTF-8 编码，`lang="zh-CN"` 声明

## 部署方式

### 方式一：云对象存储（推荐，最省事）

| 平台 | 操作 |
|------|------|
| **阿里云 OSS** | 上传全部文件到 Bucket → 设置静态网站托管 → 绑定域名（需备案） |
| **腾讯云 COS** | 上传 → 静态网站 → 索引文档设为 `index.html` |
| **七牛云 Kodo** | 上传 → 空间设置 → 静态网站托管 |
| **又拍云** | FTP/Web 上传 → 绑定域名 |

> 费用：纯静态站点流量费极低，小规模访问每月几毛到几块钱。

### 方式二：GitHub Pages + 国内加速

1. 将 `china-ready/` 目录内容推送到 GitHub 仓库
2. 在仓库 Settings → Pages 中开启，选 `main` 分支
3. 默认域名 `xxx.github.io` 国内部分区域可访问，但不稳定
4. 可在前面套一层国内 CDN，或将域名 CNAME 到 Pages 后配合加速服务

### 方式三：国内云虚拟主机 / 轻量应用服务器

- 阿里云轻量应用服务器、腾讯云轻量应用服务器（学生价约 ¥10/月）
- 使用 FTP 或宝塔面板上传 `china-ready/` 内全部文件到网站根目录
- 如果用 Nginx，确保 `charset utf-8;`

### 方式四：Cloudflare Pages（免备案）

- 上传到 GitHub → 关联 Cloudflare Pages
- 国内访问走 CF 中国边缘节点，速度尚可
- 不需要 ICP 备案即可绑定自定义域名

## 本地预览

在 `china-ready/` 目录下启动任意静态服务器：

```bash
# Python
python -m http.server 8080

# Node.js (npx serve)
npx serve .

# VS Code Live Server 插件直接右键 index.html
```

然后浏览器访问 `http://127.0.0.1:8080`

## 注意事项

1. **ICP 备案**：如果使用国内服务器（阿里云/腾讯云）绑定自定义域名，需完成 ICP 备案。但对象存储的默认域名通常可直接使用。
2. **图片更新**：如果要替换茶品图片，保持 JPG 格式，尺寸建议 800×800 左右，文件控制在 200KB 以内。
3. **价格修改**：编辑 `index.html` 中 `data-price` 属性值即可，`script.js` 会自动读取。
